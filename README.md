# RuStore Console Data Collector

Инструмент для автоматического сбора данных о продажах и выручке из RuStore (Российский магазин приложений) с последующей визуализацией в Power BI.

## 📋 Описание

Этот проект позволяет разработчикам RuStore автоматически:
- Собирать данные о покупках приложений
- Рассчитывать дневную выручку
- Экспортировать данные в удобном формате для анализа
- Визуализировать данные через готовый шаблон Power BI

## 🚀 Быстрый старт

### 1. Предварительные требования

- Python 3.12 или новее [скачать](https://www.python.org/downloads/)
- Аккаунт разработчика RuStore
- Power BI Desktop (для визуализации) [скачать](https://www.microsoft.com/ru-RU/download/details.aspx?id=58494)

### 2. Установка

```bash
# Клонируйте репозиторий
git clone https://github.com/wasiliysoft/RuStore_console_data_collector.git
cd RuStore_console_data_collector

# Установите зависимости
pip install -r requirements.txt
```

### 3. Получение токена авторизации

1. Откройте [консоль разработчика RuStore](https://console.rustore.ru)
2. Нажмите `F12` для открытия инструментов разработчика
3. Перейдите во вкладку **Application** → **Storage** → **Cookies**
4. Найдите куку `vk_dev_console_access_token` (как показано на картинке `cookie_f12.png`)
5. Скопируйте её значение (начинается с `vk1.a.`)

6. Создайте файл `authorizationToken.txt` в корне проекта
7. Вставьте токен в файл:
```
vk1.a.RrNgC******  # Ваш реальный токен
```

### 4. Запуск сбора данных

```bash
python main.py
```

Программа выполнит:
- Загрузку списка ваших приложений
- Сбор данных о покупках (с 1 июня 2023 по текущую дату)
- Сохранение двух типов отчетов:
  - `purchases/` - детальные данные о каждой покупке (CSV)
  - `revenue/` - дневная выручка по каждому приложению (TXT)

## 📊 Использование с Power BI

1. **Подготовьте данные:**
   - Запустите `main.py` для сбора актуальных данных

2. **Откройте шаблон Power BI:**
   - Запустите `PowerBI RuStore.pbit` (Power BI Template)
   - При открытии шаблон запросит параметр `csvPath`

3. **Укажите путь к данным:**
   ```
   Полный путь к каталогу purchases
   Пример: C:\Users\ВашеИмя\projects\RuStore_console_data_collector\purchases
   ```

4. **Настройте отчет:**
   - Данные автоматически загрузятся в модель
   - Используйте фильтры для выбора приложений и периода
   - Обновите отчет при поступлении новых данных

```python
start_date = datetime.date.fromisoformat('2023-06-01')
```


## ⚠️ Важные замечания

1. **Безопасность токена:**
   - Не коммитьте `authorizationToken.txt` в Git, токен предоставляет доступ к вашим данным RuStore

2. **Ограничения API:**
   - Максимальный размер страницы: 500 записей
   - Скрипт автоматически обрабатывает пагинацию

3. **Формат данных:**
   - Суммы хранятся в копейках (Power BI конвертирует в рубли)
   - Даты в формате ISO (YYYY-MM-DD)
